# 02. 角色與功能清單

## 1. 角色定義

| 角色 | 所屬端 | 說明 |
|---|---|---|
| 訪客 | 用戶端 | 未登入，可瀏覽商家頁與服務項目 |
| 會員 | 用戶端 | 已註冊使用者，與一或多家商家建立會員關係 |
| 商家管理員（Owner） | 商家端 | 店家最高權限，管理設定、方案、員工 |
| 店務人員（Staff） | 商家端 | 前台操作：代客預約、報到、核銷 |
| 服務人員（Provider） | 商家端 | 被預約的對象（教練/設計師/技師），管理自己班表、查看自己行程 |
| 平台管理員 | 平台管理端 | 平台營運方，管理所有商家 |

## 2. 用戶端（C 端）功能

### 2.1 會員中心
- 註冊 / 登入（手機 OTP、LINE 登入、Email）
- 個人資料、偏好設定（通知方式、常用服務人員）
- 我的會員卡：各商家的會員等級、有效期
- 我的資產：儲值餘額、點數、堂數卡（剩餘堂數 / 到期日）

### 2.2 瀏覽與預約
- 商家頁：介紹、服務項目、服務人員、營業時間
- 預約項目列表：名稱、服務時長、價格 / 扣減方式（扣 X 堂 / X 點 / $X）
- **可預約時段查詢**：選項目 → 選人員（或不指定）→ 顯示可預約時段
- 建立預約：確認扣減方式 → 即時扣減或到店付款 → 預約成立
- 團體課程：查看名額（8/12）、報名、候補

### 2.3 預約管理
- 我的預約列表（即將到來 / 歷史）
- **改期**：在商家允許的期限內自助改期（例如開始前 24 小時）
- 取消：依取消政策決定是否返還扣減
- **遲到通知**：一鍵告知商家「我會遲到 N 分鐘」
- 預約提醒（前一天 / 前 2 小時，LINE 或簡訊）

### 2.4 消費紀錄
- 扣減明細帳（每筆扣了什麼、剩多少）
- 購買紀錄（儲值、買卡、單次付款）與電子收據

## 3. 商家端（B 端）功能

### 3.1 商家設定
- 基本資料：名稱、地址、營業時間、時區、Logo
- **預約政策設定**（全店預設，項目可覆寫）：
  - 最早/最晚可預約時間（例：最早 30 天前、最晚 2 小時前）
  - 改期期限（例：開始前 24 小時可自助改期，之後需致電）
  - 取消政策（例：24 小時前全額返還、之內返還 50%、爽約不返還）
  - **遲到寬限**（例：遲到 15 分鐘內保留，超過視同爽約；或縮短服務時間）
  - 爽約罰則（記點、暫停預約權限 N 天、扣款）
  - 每人同時持有預約上限、審核制或即時制

### 3.2 預約項目管理（服務目錄）
- 新增/編輯項目：名稱、分類、說明、圖片
- **服務時長**：標準時長 + 前置準備 + 後置緩衝
- 型態：一對一 / 團體課（容量上限）/ 資源型（場地/設備）
- 定價與**扣減規則**：現金價、扣點數、扣堂數（可多種並存供會員選擇）
- 可服務人員綁定（哪些人員可提供此項目）

### 3.3 排班與工作時長
- 服務人員管理：邀請加入、指派可提供的項目
- **班表設定**：週期性班表（每週一~五 10:00–19:00）+ 例外（請假、調班、特殊營業日）
- 休息時間、最大連續工作時數提醒
- 資源管理：房間/設備數量（限制同時段可服務的預約數）

### 3.4 預約管理（行事曆）
- 日/週/月行事曆視圖（依人員、依資源切換）
- 代客預約、拖曳改期、手動加開時段
- 報到（Check-in）：到店報到 → 觸發扣減核銷（若採到店扣）
- **遲到處理**：標記遲到 → 系統依政策自動處理（保留/縮時/釋放時段）
- 爽約標記與罰則執行

### 3.5 會員與扣減管理
- 會員列表、標籤分群、消費紀錄
- 販售/贈送：儲值、點數、堂數卡（設定有效期）
- 手動調帳（補堂、扣堂，需填原因、留稽核紀錄）

### 3.6 通知與報表
- 通知模板管理（預約成立/提醒/改期/取消）
- 報表：營收、各項目預約量、出席率/爽約率、人員稼動率、熱門時段熱力圖

## 4. 平台管理端（總後台）功能

- 商家入駐審核、上下架、方案訂閱（免費版/專業版功能開關）
- 全域參數：簡訊額度、通知通道設定、金流串接
- 跨商家數據看板：GMV、活躍商家數、預約總量
- 客服工具：代商家查單、爭議處理
- 系統公告、操作稽核日誌
